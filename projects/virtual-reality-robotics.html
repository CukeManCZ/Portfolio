Operating a mobile robot in VR

The project connects a mobile robot with a Unity VR application. The virtual environment gives the operator a real-time view of the robot and provides the controls used to send movement commands.

My contributions

  • Teleoperation system architecture.
  • Robot communication layer.
  • Unity VR application.
  • Real-time robot visualization.
  • VR control and input mapping.
